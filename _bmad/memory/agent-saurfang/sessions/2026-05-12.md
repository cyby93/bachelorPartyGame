# Session 2026-05-12

## Task
Fix Chain Heal caster-exclusion bug (KNOWN_ISSUES.md — Classes topic).

## What Was Wrong
`_executeTargeted` in `SkillSystem.js` line ~543: when casting on another player (not self-cast), `healedIds` was initialized as `new Set([player.id])`. This pre-excluded the caster from all chain jumps. Self-cast path correctly used `new Set()`.

## Fix
`server/systems/SkillSystem.js` line 543: changed `new Set([player.id])` → `new Set()`.

Now both cast paths start with an empty healedIds. The caster is only excluded from re-healing after they've actually been healed (via `healedIds.add(current.id)` in the loop). Chain can now jump to caster regardless of how the initial target was picked.

## Files Changed

- `KNOWN_ISSUES.md` — removed resolved entry
