## Level 3 extra mechanic

I want some extra mechanic on the level 3, when we have to destroy the gates. 

I'd like stone rock boulders to be spawned on the top or bottom edge of the map and after a 3 second charge up it starts to roll to the other side of the room. 

so the rules:
  - the map would be divided into columns. It can be only logically, nem visually, but the two rooms should contain different 'columns' -> so the seconds room columns can be unlocked after the first gate is destroyed.
  - on these 'columns' the boulders can be spawned either on the top of the column or the bottom. Initially, we could spawn half the number of boulders then columns -> so the players can dodge them as standing in the clear columns.
  - the boulder speed is linear
  - the boulder path (basically the column) could be marked a bit so the players can see the boulder's path
  - if the boulder hits a player, it deals a relatively big damage (im thinking about 80 -> at level 2 the casters can barely survive, only if they are at almost full health) and slows the player 50% for 4 seconds
  - this mechanic is played every 16 seconds and it starts on cooldown when the level is started. So the mechanic sequency is the following:
      - boulders are spawned on random column edges - distributed evenly on top and bottom while three boulder should never be next to each other (only max 2)
      - they are charging for 4 seconds
      - boulders are starts moving with faster speed than a player (with speed 3 or 4 - when the player speed is around 2)
      - probably the boulder reaches the other edge in 2 seconds
      - for 10 seconds there will be a relaxed time until the whole mechanic starts again
