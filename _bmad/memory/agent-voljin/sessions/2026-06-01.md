## Task

Wire 5 SFX keys from NEW_FEATURES.md into Level 3 (Boulder mechanic) and Level 5 (Pylon mechanic).

## What Was Done

### Files Changed

**`shared/AudioConfig.js`**
Added 5 entries to `AUDIO_ONE_SHOTS`:
- `sfx_boulder_charge_up` — Level 3 boulder charge phase loop
- `sfx_boulder_loop` — Level 3 boulder rolling phase loop
- `sfx_gate_destroy` — Level 3 gate death one-shot
- `sfx_holy_tower_loop` — Level 5 pylon charging loop (players standing nearby)
- `sfx_holy_tower_cast` — Level 5 pylon active/healing loop

Added `GATE_DESTROY: 'gate:destroy'` to the Level 3 boulder section. No such event existed before — gates died silently.

**`server/GameServer.js`**
In `_updateGates()`, emit `EVENTS.GATE_DESTROY, { gateId: gate.id }` immediately after `gate.isActive = false`.

**`client/host/systems/AudioManager.js`**
- Added 4 public handlers: `handleBoulderSpawn`, `handleBoulderRoll`, `handleBoulderClear`, `handleGateDestroy`
- Added pylon early-exit dispatch at the top of `handleSkillFired` — checks `data.type` for `PYLON_SPAWN`, `PYLON_ACTIVATED`, `PYLON_EXPIRED` before Gate 1 throttle
- Added 3 private helpers: `_handlePylonSpawn`, `_handlePylonActivated`, `_handlePylonExpired`
- Loop IDs used: `boulder_charge`, `boulder_loop`, `pylon_charge`, `pylon_active`

**`client/host/main.js`**
- Added `BOULDER_SPAWN` socket handler → `audio.handleBoulderSpawn`
- Added `BOULDER_ROLL` socket handler → `audio.handleBoulderRoll`
- Updated `BOULDER_CLEAR` to also call `audio.handleBoulderClear`
- Added `GATE_DESTROY` socket handler → `audio.handleGateDestroy`

### Key Decisions

- Pylon events are piggybacked on `SKILL_FIRED` — dispatch by `data.type` before skill audio routing avoids spurious generic-family sounds.
- Fixed pylon loop IDs (`pylon_charge`, `pylon_active`) are safe because only one pylon exists at a time (GameServer enforces `_pylons.size === 0` before spawn).
- `handleBoulderSpawn` stops `boulder_loop` defensively in case a prior cycle didn't clear.
- Build failure during verification was a pre-existing missing sprite (`druid/idle/south/2.png`), not caused by these changes. JS syntax checks passed clean.
