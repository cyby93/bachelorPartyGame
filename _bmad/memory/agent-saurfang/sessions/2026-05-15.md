# Session 2026-05-15 — Shield Partial Block Rework

## Task
Change Warrior Shield Block and Paladin Divine Shield from 100% damage block to 60% base damage reduction, upgradeable to 90% (+10% per upgrade tier).

## Changes

### shared/SkillDatabase.js
- Added `shieldReduction: 0.6` to Shield Block (Warrior S3)
- Added `shieldReduction: 0.6` to Divine Shield (Paladin S2)

### shared/UpgradeConfig.js
- Added `shieldReduction: 0.1` to each of the 3 upgrade tiers for Shield Block
- Added `shieldReduction: 0.1` to each of the 3 upgrade tiers for Divine Shield
- Existing cooldown/arc bonuses preserved alongside the new reduction delta

### server/systems/SkillSystem.js — `_executeShield`
- On START: stores `config.shieldReduction ?? 0.6` onto `player.shieldReduction`

### server/entities/ServerPlayer.js
- Added `this.shieldReduction = 0` to constructor
- Added `shieldPassthroughAmount(attackerX, attackerY, amount)` helper — returns reduced damage if in shield arc, otherwise full amount

### All damage callsites (GameServer.js, IllidanEncounter.js, TrainingDummy.js, SkillSystem.js)
- Replaced `if (p.isShieldBlocking(x, y)) return` pattern with `shieldPassthroughAmount` pattern
- Fully blocked (amount=0) still returns early / emits 'blocked'
- Partially blocked deals reduced damage and emits 'damage' event

## Notes
- Shadow Demon "instant kill" (10× maxHp) with 60% shield = 4× maxHp still kills. With 90% = 1× maxHp still kills. The mechanic remains lethal unless Cyby decides to add a special case.
- `isShieldBlocking` kept as-is (internal only, used by `shieldPassthroughAmount`)
