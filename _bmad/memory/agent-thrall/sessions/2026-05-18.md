## Session — Rogue melee rect VFX (Sinister Strike)

**What happened:** Saurfang implemented a rectangular melee hitbox for the Rogue's Sinister Strike. Implemented matching VFX: `meleeRect()` in `OneShotEffectSystem.js` and branched the `MELEE` type handler in `VFXManager.js`.

**Key outcomes:**
- `OneShotEffectSystem.js`: added `meleeRect(x, y, facing, range, width, color)` — oriented rectangle using forward/lateral axis decomposition. 0.15s duration, same as `meleeArc`. Rectangle "lunges" forward (range grows 60%→100% during animation). Three draw passes: filled body (class color, alpha 0.30), outer edge stroke (white, 0.55), bright leading edge highlight (white, 0.80) to accentuate forward reach.
- `VFXManager.js` MELEE handler (line 73): branches on `d.width != null` — calls `meleeRect` when width is present, `meleeArc` otherwise. All other MELEE skills unaffected.
- Axis math: `fx = cos(facing)`, `fy = sin(facing)` (forward); `lx = -sin(facing)`, `ly = cos(facing)` (lateral/left perpendicular). Four corners computed from `hw = width/2`.

**Observations:** Used the same polygon path pattern as `moonfireBeam`. The bright leading-edge highlight at the front of the rectangle communicates forward reach direction clearly — matches the "precise blade thrust" design intent.

**Follow-up:** None. Effect tuning (alpha, animation curve) can be adjusted freely in `OneShotEffectSystem.meleeRect()`.
