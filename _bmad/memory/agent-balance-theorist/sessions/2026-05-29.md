# Session 2026-05-29

## Task
Add Hammer of Light `holyStrikeProc` triggered heal to HPS calculator.

## Change Made
**File:** `tools/hps-calculator.js`

Added `MELEE` case to `getInstantHeal`:
```js
case 'MELEE':
  if (skill.holyStrikeProc) {
    const p = skill.holyStrikeProc
    return (p.healMin + p.healMax) / 2 / p.procEvery
  }
  return 0
```

## Math
- Hammer of Light: `cooldown: 1000ms`, instant-cast, `procEvery: 4`, avg heal `(12+16)/2 = 14`
- Expected heal per activation: `14 / 4 = 3.5 HP`
- Over 5-min fight: 300 activations → 75 procs → 1050 HP → **3.5 HPS**

## Result
Paladin HPS (off-role): `Consecration 8.0 + Hammer of Light 3.5 = 11.5 HPS total`

DPS calculator: no change required — `holyStrikeProc` is a heal proc, does not affect damage output.
