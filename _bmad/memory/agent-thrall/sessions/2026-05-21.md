## Session D — Portal Tuning (follow-on to C)

### Changes Made

1. **All gates always visible** — Server `_tickZoneSelector` now uses `CAMPAIGN.length` (6) as the fixed zone grid instead of `unlockedLevelCount`. Zone width is always `arenaWidth/6`. Locked zones (index >= unlockedLevelCount) are detected in the grid but not counted. Renderer always builds 6 portals; locked ones get `alpha:0.40`, `tint:0x666666`, overlays cleared.

2. **Portal size 50% larger** — Sprites rendered at 120×120px (up from 80×80). Updated constants: `PORTAL_W/H=120`, `GLOW_CY=48`, `GLOW_RX=42`, `GLOW_RY=33`. Rune positions scaled: y=[30,54,78], x offsets ±15px from pillar edges.

3. **Portals overflow out of top edge** — `container.y = -30` (was +30). Top half of sprite clips outside the arena; players activate by standing in the visible bottom half. `ZONE_HEIGHT` updated to 90 in both renderer and server (= -30 + 120 = 90px in arena coords). Ground boundary line moved to `PORTAL_H - 2` (local sprite coords).

4. **Silver top border removed for training grounds** — `HostGame._rebuildBackground` stores `this._activeSceneName = name` before `setArenaSize`. When scene is `trainingGrounds`, the silver stroke draws 3 sides only (`moveTo(0,0).lineTo(0,H).lineTo(W,H).lineTo(W,0)`) — top edge omitted so portals overflowing the edge don't bleed silver through their semi-transparent sprites.

### Final Constants
- `container.y = -30`
- `PORTAL_W = PORTAL_H = 120`
- `ZONE_HEIGHT = 90` (renderer + server)
- Server zone grid: always `CAMPAIGN.length` = 6 wide

## Session B — Level Border Alignment

### Task
Move the level border silver line exactly to the edge of the floor tiles.

### What Happened
User reported the silver border around each level was visibly ~20px inset from the floor tile boundary.

**Root cause:** `_rebuildBackground()` in `HostGame.js` had two final strokes in the wrong order:
1. `rect(16, 16, W-32, H-32)` silver stroke width 3 — center at 16px inset
2. `rect(0, 0, W, H)` dark frame stroke width 10 — drawn ON TOP, covering 0-5px from edge

**Fix:** Swapped draw order and moved silver rect to `(0, 0, W, H)`:
1. Dark frame drawn first
2. Silver line drawn last at `rect(0, 0, W, H)` width 3 — centered on floor tile boundary

File: `client/host/HostGame.js`, `_rebuildBackground()`, ~line 593.
