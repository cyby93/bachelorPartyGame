# Session 2026-05-19b — KNOWN_ISSUES pass (Level 5 / Phase 4)

## Fixes shipped

**1. Pet immune targeting** (`server/entities/ServerMinion.js`)
`_findNearest()` and `_findNearestWithinRadius()` both had the same bug — boss check didn't guard `isImmune`. During Phase 2 Illidan is airborne + immune; pets were running at him instead of the Flames of Azzinoth.
Fix: added `&& !gs.boss.isImmune` to both boss checks.

**2. Summon Shadow Demons never firing** (`shared/IllidanConfig.js`)
Root cause: DEMON_FORM ability array was [agonizingFlames, shadowBlast, summonShadowDemons]. Shadow Blast has `castTime: 2500` — `updateAbilities()` sets `activeCast` and `break`s the loop. With its cooldown (1000ms) shorter than its cast time (2500ms), it perpetually claimed the slot before summonShadowDemons was reached.
Fix: reordered to [agonizingFlames, summonShadowDemons, shadowBlast] — cast ability last so non-cast abilities fire first.

**3. Agonizing Flames — emit `EVENTS.SKILL_FIRED`** (`server/systems/IllidanEncounter.js`)
Added after splash damage loop, before DoT push. Payload: `type:'EXPLOSION'`, `skillName:'Agonizing Flames'`, primary target x/y, `radius: attack.splashRadius`, `color:'#ff8800'`. Thrall hooks this for VFX.

**4. Shadow Blast fireball impact — emit `EVENTS.SKILL_FIRED`** (`server/systems/IllidanEncounter.js`)
Added in `_tickFireballs()` straight-projectile contact block, after damage loop, before splice. Payload: `type:'EXPLOSION'`, `skillName: fb.sourceSkill`, impact x/y, `radius: fb.splashRadius`, `color: fb.color`.

**5. Pyroblast splash — emit `EVENTS.SKILL_FIRED`** (`server/systems/SkillSystem.js`)
Added `gs.io.emit('skill:fired', ...)` in `_handleProjectileHit` `onImpact` block, immediately after `_executeAOEAtPoint`. Fires for any projectile with `onImpact` (not just Pyroblast — correct blanket behavior). Guard: `if (gs.io)`.
