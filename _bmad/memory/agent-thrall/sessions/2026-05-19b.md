# Session 2026-05-19b — Fire/Shadow nova rings for Illidan Phase 4

## New methods added to `OneShotEffectSystem.js`

**`fireNovaRing(x, y, radius)`** — 0.38s expanding ring.
Colors: `0xff4400` inner / `0xff8800` outer. Expanding wave + static boundary ring at full radius.
Used for: Agonizing Flames, Pyroblast.

**`shadowNovaRing(x, y, radius)`** — 0.38s expanding ring.
Colors: `0x6600aa` inner / `0xaa44ff` outer. Same structure.
Used for: Shadow Blast (Illidan demon form).

## Static boundary ring pattern (new — matches Frost Nova readability)
Both methods include a **static `width: 3` stroke at full `radius`** that exists from the start and fades. This is what tells players where the splash edge is — the expanding wave is the "arrival" signal, the static ring is the "boundary" signal. Matches the Frost Nova outer ring pattern.

Color of the static boundary matches the ability:
- Fire: `0xff8800` (orange)
- Shadow: `0xaa44ff` (violet)

## New named-skill handlers in `VFXManager._buildHandlers()`

| Skill | Effect |
|---|---|
| `'Agonizing Flames'` | `fireNovaRing + hitSpark + impactFlash` (zone placement, no explosionBurst) |
| `'Pyroblast'` | `explosionBurst + fireNovaRing + hitSpark` (detonation + splash boundary) |
| `'Shadow Blast'` | `shadowNovaRing + hitSpark + impactFlash` |

## Design note
Two dedicated ring methods rather than parameterizing `frostNovaRing` — keeps methods self-documenting. `frostNovaRing` hardcodes ice geometry (8 spike radials, cyan fill); parameterizing would thread color through 4 drawing calls and break the semantic clarity of the name.
