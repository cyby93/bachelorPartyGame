## Session 4 — 2026-05-20, Searing Totem multi-target fix + bar scaling

Searing Totem DPS is now flat 4.8 regardless of target count.

## Session 5 — 2026-05-20, Pyroblast multi-target splash fix

**What happened:** Cyby reported Pyroblast splash damage not counting towards multiple enemies in the DPS sim.

**Key outcomes:**
- Root cause: `getInstantDamage` CAST branch added `p.onImpact.damage` as flat +30 regardless of `TARGET_COUNT`. The AOE splash at impact point should hit all N targets, but only the direct projectile hit is single-target.
- Fix in `dps-calculator.js` only (upgraded calc has no TARGET_COUNT — single-boss sim, correct as-is): `const splashScale = p.onImpact.type === 'AOE' ? TARGET_COUNT : 1`.
- Single-target: unchanged (×1 splash = 72+30=102 per cast, same as before).
- 3-target: Pyroblast 13.6 → 21.6 DPS (+8.0). Total Mage DPS: 22.8 → 30.8.
- Header comment updated to reflect that CAST onImpact AOE scales by N.
- SkillDatabase.js was modified (M) before this session — Hunter DPS drifted 32.5→29.3, Mage 21.2→22.8. These are upstream changes, not calc bugs.

**Observations:** Same pattern as Tranquility and Searing Totem fixes — AOE subtype checks were missing from multi-target scaling paths.

**Follow-up:** None. Pyroblast splash now correctly models as: 72 to primary + 30×N to all targets.
