## Session — Projectile impact VFX

**Context:** Basic projectiles (Fireball, Arrow, Shadow Bolt etc. without `onImpact`) had no visual feedback on hit. The sprite snapped to the hit position on Tick N STATE_DELTA, sat motionless for ~50ms, then `detach()` hid it. No flash — just disappearance.

**Fix:** `BaseRenderer._syncProjectiles` — added `this.vfx?.triggerImpact(s.container.position.x, s.container.position.y, s._color)` immediately before `s.detach()`. `triggerImpact` fires `hitSpark` (particles) + `impactFlash` (ring burst) using the projectile's own color (`s._color` is already stored as hex int on `ProjectileSprite`).

**Decision:** Client-side at `detach()` time — no new server events. The 1-tick (~16ms) timing offset vs a true server event is imperceptible. Spurious flash for out-of-range projectiles accepted as a rare edge case. Boss fireballs (`_syncBossFireballs`) intentionally excluded — they have EXPLOSION events already.

## Session — Cleave + Hammer Swing hitbox VFX

**What happened:** Cyby noticed the MELEE arc VFX didn't match the server hitbox geometry. Warrior Cleave (180°) was only showing ~90° — the generic `meleeArc` hardcoded `Math.PI/4` max halfArc regardless of skill config. Paladin Hammer Swing (90°) matched by coincidence but animated as a sweep instead of a slam.

**Key outcomes:**
- `GameServer.js`: added `skillAngle: config.angle ?? null` to `_skillPayload` so client VFX can read actual cone width
- `OneShotEffectSystem.js`: added `cleaveWipe(x, y, facing, halfAngle, range)` — rotational sweep from left edge to right edge of cone, 0.22s, red-orange fill with white blade edge
- `OneShotEffectSystem.js`: added `hammerStamp(x, y, facing, halfAngle, range)` — instant full-cone golden stamp, 0.22s, 4 crack lines radiating at impact, bright inner tip highlight
- `VFXManager.js`: registered `'Cleave'` and `'Hammer Swing'` as named skill handlers; both use `d.skillAngle` with fallback to config defaults

**Observations:** Generic `meleeArc` still used as fallback for other MELEE skills (e.g. Death Knight Obliterate, Rogue). Only Cleave and Hammer Swing have custom handlers.

**Follow-up:** None — fully implemented and verified.
