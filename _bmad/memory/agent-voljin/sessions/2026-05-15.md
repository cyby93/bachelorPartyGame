# Session 2026-05-15

## What Was Built

### Reactive Combat VO — Illidan Level 6
Three new reactive voice triggers for Illidan, all using the new `BOSS_VO` (`boss:boss_vo`) protocol event. This event carries no subtitle text and applies zero ducking — it plays straight over the mix.

**Kill taunt** — fires when a player dies, 20s cooldown.
**Attack cry** — fires on melee contact and ability dispatch, 3–10s random cooldown.
**Wound cry** — fires when Illidan takes damage (via `boss.onTakeDamage` callback), 3–10s random cooldown.

All cooldowns are tunable in `ILLIDAN_CONFIG.reactiveVo` in `shared/IllidanConfig.js`.

### SFX Ducking During Cinematic Dialog
`handleDialogLine` now passes `{ duckSfx: true }` to `_duckForVoice`. During phase transitions and level-opening dialog sequences, the sfx bus drops to 20% (`AUDIO_DUCKING.voiceSfxDialogMultiplier`). Reactive VO (`handleBossVo`) and all non-dialog events remain unaffected.

The `_sfxDuck` multiplier is applied in:
- `_applySettings()` → WebAudio sfx bus gain and looping sfx HTML volumes
- `_playHtmlOneShot()` → one-shot sfx HTML volumes

On `handleDialogClear` / `_duckForVoice(false)`, sfx restores with a smooth ramp.

### Reactive VO Suppression During Cinematic
`handleBossVo` checks `_activeVoiceEl` first — if a cinematic line is playing, the reactive cue is silently dropped. No interruption, no overlap.
