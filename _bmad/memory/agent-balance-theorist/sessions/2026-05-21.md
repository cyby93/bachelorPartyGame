# Session 2026-05-21

## Task
Fix Cleave multi-target scaling in dps-calculator.js.

## Problem
User reported Cleave only hitting 1 target in 3- and 5-target simulations.

Root cause: `getInstantDamage()` in `tools/dps-calculator.js` had:
```js
case 'MELEE':
case 'PROJECTILE':
  return skill.damage ?? 0
```
The `MELEE` case shared a fall-through with `PROJECTILE` and never scaled by `TARGET_COUNT`.

## Scope
Four MELEE skills in SkillDatabase:
- Cleave (Warrior): `angle: Math.PI` (180°) — cone, should scale ×N
- Hammer Swing (Paladin): `angle: Math.PI/2` (90°) — cone, should scale ×N
- Death Strike (DeathKnight): `angle: Math.PI/3` (60°) — cone, should scale ×N
- Sinister Strike (Rogue): no `angle` — single-target swing, should NOT scale

## Fix
Split the shared `MELEE`/`PROJECTILE` case in `tools/dps-calculator.js`:
```js
case 'MELEE':
  return (skill.damage ?? 0) * (skill.angle ? TARGET_COUNT : 1)
case 'PROJECTILE':
  return skill.damage ?? 0
```
Logic: presence of `skill.angle` means cone attack → multi-hit.

## dps-calculator-upgraded.js
No fix needed — that tool has no TARGET_COUNT (single-target only).

## Verified DPS numbers
| Skill | 1T | 3T | 5T |
|---|---|---|---|
| Cleave | 8.0 | 24.0 | 40.0 |
| Hammer Swing | 8.3 | 25.0 | 41.7 |
| Death Strike | 10.0 | 30.0 | 50.0 |
| Sinister Strike | 14.4 | 14.4 | 14.4 |

All scale exactly ×N (or ×1 for no-angle skills).

## Balance Impact
Melee classes (Warrior, Paladin, DeathKnight) now correctly outscale ranged in AoE scenarios — which is the intended design for their niche. Rogue stays single-target focused.

## Session 2: Realistic multi-target density model

### Problem
Flat ×N scaling assumed all N enemies are always in every hit zone — a ceiling, not a realistic average. User requested a physically-grounded model.

### Model Implemented
Three geometric formulas based on actual SkillDatabase geometry:
- **Cone (MELEE + angle)**: `N × angle/(2π)` — fraction of surrounding enemies in swing arc
- **AOE_SELF circle**: `N × min(1, (r/ZONE)²)` — combat zone density model
- **Placed circle** (aimed AOE, traps, splashes): `1 + (N-1) × min(1, (r/SPREAD)²)`
- **DoT coverage**: `min(N, 1 + (N-1) × 0.5)` — realistic multi-target maintenance (Option C chosen by Cyby)

### Parameters (all overridable via CLI)
- `--density=tight|normal|loose` (presets), or raw `--zone=N --spread=N --dot-coverage=F`
- Defaults (normal): zone=200px, spread=100px, dotCoverage=0.5

### Key Results at N=5, normal density
| Ability | Old | New |
|---|---|---|
| Cleave (180°) | ×5.0 | ×2.5 |
| Death and Decay (120px) | ×5.0 | ×5.0 (clamped, placed model) |
| Bladestorm (70px) | ×5.0 | ×0.61 |
| Corruption DoT | ×5.0 | ×3.0 |
| Holy Nova (200px) | ×5.0 | ×5.0 |
| Sinister Strike | ×1.0 | ×1.0 |

### Notable balance signal
At N=10, Death Knight becomes top DPS class due to Death and Decay (120px placed, scales to ×N) overtaking all others. Melee cone classes scale moderately. Rogue/Shaman are flat — fully single-target.

- `tools/dps-calculator.js` only. `dps-calculator-upgraded.js` unchanged.
