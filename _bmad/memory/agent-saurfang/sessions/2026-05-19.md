# Session 2026-05-19

## Task
Fix Shadow Blast (demon form, Phase 4) hitting players when not visually close.

## Root Cause
`_tickFireballs()` in `IllidanEncounter.js` used `fb.splashRadius` (80) as the **contact detection radius** for straight projectiles. The actual check:

```js
playerHitsCircle(p.x, p.y, fb.x, fb.y, fb.splashRadius)
// → ellipse threshold: PLAYER_RADIUS_X+80=95 (X), PLAYER_RADIUS_Y+80=110 (Y)
```

The fireball (visual radius: 10) was registering a hit when any player was within ~95px on X or ~110px on Y of the projectile center — far before visual contact.

## Fix
`IllidanEncounter.js` lines ~727–750:
- **Contact detection** now uses `fb.radius` (10) so the fireball must visually reach the player
- **Detonation splash** still uses `fb.splashRadius` (80) to AoE-damage nearby players at impact

Two-pass approach:
1. Scan all players with `fb.radius` → if any contact, detonate
2. On detonation, damage all players within `fb.splashRadius`

## Verified
The homing Azzinoth fireball path was untouched; it uses a distance-to-target check (`dist <= HIT_DIST + fb.splashRadius`) which is correct for a homing projectile.

## Nothing Flagged for Thrall
No VFX change needed — the collision fix is server-only. The fireball's visual radius is unchanged.
