### Behaviour changes

1. **Downed — crawl toward nearest alive character**
   - `player.isDowned` no longer bails out. Bot pushes a move vector toward the closest non-downed, non-host player.

2. **Idle during dialog / non-combat scene**
   - When `isDialogRunning()` returns true (Levels 5 & 6 opening cutscenes) OR scene ≠ 'battle'/'bossFight', bots gentle-wander. No skills fired.

3. **Low-HP retreat to healer**
   - Below 30% HP, non-healer bots move toward the nearest living healer (Priest/Druid/Shaman).
   - If no healer exists, fall back to the old "flee from nearest enemy" behaviour.
   - Healer bots still flee from the nearest threat.

4. **Objective-aware movement**
   - `destroyBuildings` levels: ~65% of bots move toward the nearest undestroyed building. Skills naturally hit buildings (SkillSystem already handles projectile/melee/AOE vs buildings).
   - `destroyGates` levels: same but targets only the nearest `isActive && !isDead` gate.
   - `objectiveBias` is a stable random value per bot, set once on first tick. Creates natural task division without explicit assignment.
   - Healer bots are excluded from objective movement — they always follow the group.
   - Skill aim: always toward the nearest actual enemy first; objective used as fallback if no enemies.

5. **Smart skill selection**
   - Replaced round-robin timer (every 3 ticks, blind cursor advance) with an eligibility-gate loop:
     - Every 2 ticks, iterate slots from current cursor
     - Skip if `skillNextAllowed[slot] > now`
     - Skip if `_isEligible()` returns false
     - Fire first eligible; advance cursor past it
   - `skillNextAllowed` now tracks `castTime + cooldown` (was: only castTime). Bots no longer spam slots that are server-side blocked.

6. **`_isEligible()` — per-skill conditions**
   - `Mass Resurrection`: only when ≥1 downed ally
   - `Blink`, `Vanish` (STEALTH), `DASH` type: only when enemy within 220px
   - `HEAL_ALLY`: only when an ally exists below 85% HP
   - `AOE_SELF`: only when enemy within `radius + 80` px
   - `TARGETED`: only when enemy within skill's `range`
   - `MELEE`: only when enemy within `range × 1.5`
   - `SHIELD`: only when enemy within 200px
   - `CHANNEL/BEAM` (Drain Life): only when enemy within skill's `range`
   - `CHANNEL/UNTARGETED` (Tranquility): when enemy within 450px OR any ally below 75% HP
   - `BUFF/TARGETED` (Power Word: Shield etc.): only when an injured ally exists
   - `BUFF` (non-targeted): only when enemies present
   - Everything else (PROJECTILE, CAST, SPAWN): fire whenever a skill target exists

7. **Channel movement suppression**
   - When a CHANNEL skill fires, `botState.channelUntil = now + castTime`
   - While `now < channelUntil`, movement input is suppressed
   - Exception: if an enemy is within 85px (melee range), bot can still move to dodge
