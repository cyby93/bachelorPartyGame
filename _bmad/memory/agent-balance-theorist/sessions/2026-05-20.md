## Session — HPS calculator Tranquility bug fix

**What happened:** Cyby reported Druid's Tranquility HPS was identical across single-target, 3-target, and 5-target modes.

**Key outcomes:**
- Root cause: `getInstantHeal` CHANNEL branch (payload.healAmount path) had no `TARGET_COUNT` multiplier.
- Fix: check `skill.payload.type === 'AOE'` and multiply by `TARGET_COUNT`. One-line change in `hps-calculator.js` line ~72.
- Verified: Tranquility now scales ×1 / ×3 / ×5 correctly at T=1/3/5.
- MEMORY.md open question closed.

**Observations:** The fix was simpler than the April 21 note suggested ("would need an AOE flag") — the AOE flag was already on `payload.type`, just not checked.
